# 드랍세트 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `SetRecord.isDrop` 플래그로 드랍세트를 기록 — 세션 화면 `↓ 드랍 추가`(80% 프리필), 드랍 앞 휴식 타이머 억제, `3-1` 라벨을 세션·기록·홈·편집에 일관 표시.

**Architecture:** 평평한 sets 배열 + 선택 필드 1개(`pairedWithNext`와 동일 패턴). 표시 라벨은 순수 함수 `setLabels`, 드랍 무게는 표시 단위 스텝에 맞추는 `dropWeight`. 선두 드랍은 읽기 시 자가 치유 + 쓰기 시 정리.

**Tech Stack:** React 18 + TypeScript, Dexie, vitest

**스펙:** `docs/superpowers/specs/2026-08-11-drop-set-design.md`

## Global Constraints

- Dexie store 스키마(인덱스) 변경 금지 — 선택 필드만 (`isDrop?: boolean`)
- 저장 무게는 항상 kg(소수 2자리); 드랍 무게 계산은 **표시 단위에서** 20% 낮춘 뒤 입력 스텝(kg 0.5 / lb 2.5)에 반올림 → kg으로 저장
- 배열 첫 세트의 `isDrop`은 본세트로 취급(자가 치유). 쓰기 경로(`finishSession`·편집 저장·`buildEntry`)에서도 선두 플래그 정리
- 볼륨·최고 무게·PR 계산 로직 변경 금지 (드랍도 볼륨에 포함되는 현재 동작이 정답)
- 본세트 라벨은 기존과 동일(`1`,`2`,`3`)해야 함 — 기존 테스트의 `세트 1 무게` 등 aria-label 무변경 통과
- UI 문구 한국어, 표기는 사용자 어휘 "드랍" 사용, 새 npm 의존성 금지
- 테스트 실행: `npx vitest run <파일경로>` (전체는 `npm test`, 현재 182개)

```ts
// 무게 입력 스텝 (lb 2.5 / kg 0.5)
export function stepFor(unit: WeightUnit): number {
  return unit === 'lb' ? 2.5 : 0.5;
}

export const DROP_RATIO = 0.8;

// 드랍 세트 기본 무게: 표시 단위에서 20% 낮춘 뒤 입력 스텝에 맞춰 반올림 → kg 저장값
export function dropWeight(kg: number, unit: WeightUnit): number {
  const step = stepFor(unit);
  const dropped = kgToDisplay(kg, unit) * DROP_RATIO;
  return displayToKg(Math.round(dropped / step) * step, unit);
}
```

```ts
// 선두 세트의 isDrop 해제 — 짝(본세트)이 사라진 드랍은 본세트로 승격
export function dropHeadCleaned(sets: SetRecord[]): SetRecord[] {
  return sets.length > 0 && sets[0].isDrop
    ? [{ ...sets[0], isDrop: undefined }, ...sets.slice(1)]
    : sets;
}
```

```ts
// 세트 표시 라벨: 본세트는 1,2,3…, 드랍은 직전 본세트 번호에 -1,-2…
// 배열 첫 세트의 isDrop은 무시하고 본세트로 취급 (짝 잃은 플래그 자가 치유 — groupsOf와 동일 원칙)
export function setLabels(sets: { isDrop?: boolean }[]): string[] {
  let main = 0;
  let drop = 0;
  return sets.map((s, i) => {
    if (s.isDrop && i > 0) {
      drop += 1;
      return `${main}-${drop}`;
    }
    main += 1;
    drop = 0;
    return `${main}`;
  });
}
```
