# 운동 소요 시간 표시 + 달력 과거/미래 구분 설계

날짜: 2026-08-14

## 목적

① 완료한 세션의 총 소요 시간을 요약 화면과 펼침 상세에서 볼 수 있게. ② 홈 달력에서 아직 오지 않은 날을 흐리게 표시해 지난날과 한눈에 구분.

## 요구사항 (사용자 확정)

- 시간 표시 위치: 요약 화면 + 펼침 상세(SessionDetails — 기록 탭·홈 달력 공용)
- 달력: 지난날과 미래 날짜의 색을 다르게

## 구성 요소

### 1. `sessions.ts` — `sessionDuration(session): string | null`

- `finishedAt - startedAt`을 분 단위 반올림(최소 1분): `52분`, `1시간`, `1시간 12분`
- **null 반환(표시 생략)**: 미완료 세션, 0 이하, **12시간 이상** — 백데이트 세션은 startedAt이 과거 정오·finishedAt이 실제 입력 시각이라 소요 시간이 무의미하게 커지는 것을 걸러냄. 자정 넘김 실제 운동(<12h)은 정상 표시
- 표시 전용 순수 함수 (`sessionTitle`·`setLabels`와 같은 자리), 저장 데이터 무변경

### 2. 표시

- `SummaryScreen` card-h: `{이름} · {날짜} · {N}개 운동 · 1시간 12분` (null이면 생략)
- `SessionDetails` 맨 아래: `⏱ 운동 시간 52분` (회색 d, null이면 생략) — 기록 탭·홈 달력 동시 반영

### 3. `MonthCalendar` + CSS — 미래 날짜 흐림

- 셀 분류: 운동한 날 `.on`(파란 ✓) > 오늘 `.today`(테두리) > **미래 `.future`(신규)** > 지난날(기존 회색)
- `.day .dot.future { background: transparent; color: var(--gray-3); }` — 지난날은 회색 배경 유지, 미래는 배경 없이 더 연한 숫자
- 동작 무변경 (미래 날짜 선택 가능, 기록 추가 버튼은 기존대로 미래엔 없음)

## 에러/엣지 케이스

- 백데이트 세션: 시간 줄 자체가 생략됨 (12h 컷)
- 1분 미만 실제 완료: `1분`으로 표시
- 오늘 날짜: `.today` 우선 (future 아님), 운동한 미래 날짜는 불가능하지만 규칙상 `.on` 우선

## 테스트

- `sessionDuration`: 52분/1시간/1시간 12분/미완료 null/12시간 이상 null/음수 null/1분 미만 → 1분
- 요약 헤더에 `· 1시간` 표시, 펼침 상세에 `⏱ 운동 시간 1시간` 표시 (테스트 헬퍼가 +1h로 세션 생성)
- 달력: 다음 달 날짜에 `future` 클래스, 지난달 날짜엔 없음
- 기존 테스트 무변경 통과

## 범위 제외 (YAGNI)

- 세션 행에 시간 표시, 운동별 소요 시간, 백데이트 세션의 수동 시간 입력
