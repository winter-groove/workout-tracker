# 기록 탭 세트 표 가독성 개선 설계

날짜: 2026-08-03

## 목적

기록 탭 세션 펼침 상세의 운동별 세트가 우측 작은 회색 한 줄("60×10, 60×8")이라 안 보임 → 운동명 헤더 + 3열 세트 표(세트|무게|횟수)로 개편.

## 요구사항 (사용자 확정)

- 세션 터치 → 아래로 펼쳐지며 운동별 세트·무게가 한눈에
- 세션 화면과 같은 그리드 감성의 읽기 전용 표

## 구성 요소 — `HistoryScreen.tsx` + `styles.css`

- 펼침 상세의 운동 블록: **운동명(굵게, 🏆 포함)** → **3열 표** (헤더 `세트|무게({unit})|횟수` + 세트별 행, 무게는 `kgToDisplay` 적용) → 기존 증감·PR 요약 줄 유지
- 접힘 행 좌측 텍스트 끝에 `▾/▴` 펼침 표시 추가 (발견성)
- CSS 신규 1개: `.set-view { display: grid; grid-template-columns: 40px 1fr 1fr; gap: 6px; text-align: center; font-size: 13.5px; font-weight: 600; }`
- 범위 한정: 세션 펼침 상세만. "운동별로 보기"(fmtSets 유지)·홈 달력 목록·요약 화면 무변경

## 에러/엣지 케이스

- 기존 테스트의 세션 행 매칭은 정규식(`/1개 운동/`)이라 ▾ 추가에 안전 — 정확 문자열 매칭 테스트가 있으면 함께 갱신
- lb 모드: 표 무게·헤더 단위 반영
- 삭제된 운동 entry: 이름 fallback 그대로, 표는 정상

## 테스트

- 펼침 시 표 헤더(`무게(kg)`)와 세트 무게 값 표시
- lb 모드 표 표시(`무게(lb)`, 변환 값)
- 기존 요약 줄·수정하기·기록 삭제·race 테스트 무변경 통과

## 범위 제외 (YAGNI)

- 펼침 애니메이션, 세트 완료 시각 표시, 운동별 보기 개편
