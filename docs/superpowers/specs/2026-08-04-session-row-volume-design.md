# 세션 행 총볼륨 표시 설계

날짜: 2026-08-04

## 목적

기록 탭·홈 달력의 접힘 세션 행을 `가슴 운동 · 3개 운동 · 총볼륨 1100kg ▾` 형식으로 — 펼치지 않아도 총볼륨이 보이게.

## 요구사항 (사용자 확정)

- 형식: `{세션 이름} · {N}개 운동 · 총볼륨 {kg}kg` (총볼륨은 항상 kg)
- 적용 범위: 기록 탭 세션 목록 + 홈 달력 날짜별 세션 행 (동일 형식)

## 구성 요소

- `progress.ts`에 `sessionVolume(session): number` 신설 — `entries`의 `volume(sets)` 합(원본 kg). DB 조회 없는 순수 계산이라 접힘 행에서도 비용 없음. 완료 세션은 완료 세트만 남아 있어 SessionDetails 운동별 볼륨 합과 항상 일치
- `HistoryScreen`·`HomeScreen` 세션 행 span에 `· 총볼륨 {kgToDisplay(sessionVolume(s), 'kg')}kg` 추가 (▾/▴ 앞)
- **중복 제거**: 행에 총볼륨이 상시 보이므로 `SessionDetails` 하단 총볼륨 줄은 삭제 (펼쳐도 행이 그대로 위에 보임). `SummaryScreen`의 총볼륨 줄은 유지하되 `sessionVolume`으로 합산 통일

## 테스트

- `sessionVolume` 단위 테스트 (다중 entry 합)
- 기록 탭: 접힘 행에 총볼륨 표시(기존 '펼침 상세 총볼륨' 테스트를 행 기준으로 갱신), 펼쳐도 총볼륨 표기는 1곳뿐
- 홈: 날짜 선택 시 행에 총볼륨 표시
- 기존 테스트: 행 매칭이 정규식(`/1개 운동/`)이라 안전, 요약 화면 총볼륨 테스트 무변경 통과

## 범위 제외 (YAGNI)

- 천 단위 콤마, 행 레이아웃 개편, lb 병기(총볼륨은 kg 고정)
