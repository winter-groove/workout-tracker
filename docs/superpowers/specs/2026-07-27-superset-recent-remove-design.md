# 슈퍼세트 묶기 + 최근 운동 상위 표시 + 세션 중 운동 빼기 설계

날짜: 2026-07-27

## 목적

사용자 피드백 3건: (1) 두 운동을 번갈아(슈퍼세트) 할 때 세트마다 이전/다음 전환이 불편 → 묶어서 한 화면에, (2) 운동 736개 중 "내가 하던 운동"을 찾기 어렵고 마지막으로 뭘 했는지 헷갈림 → picker에서 기록 있는 운동을 최근순으로 상위 표시 + 마지막 수행일, (3) 세션 중 잘못 추가한 운동을 뺄 방법이 없음 → 운동 빼기.

## 요구사항 (사용자 확정)

- 슈퍼세트: **묶기 방식** — 묶으면 두(이상) 운동의 세트가 한 화면에 위아래로 표시, 해제 가능, 새로고침에도 유지
- picker: 상단 "최근 한 운동" 구간(최근 수행순 + 마지막 수행일 표시) + "전체 운동" 구간, 검색·부위 필터는 양쪽 적용
- 운동 빼기: 완료 세트 있으면 확인창, 없으면 즉시. 묶임 정리 포함

## 데이터 모델

`SessionEntry`에 선택 필드 추가 (Dexie 스토어/인덱스 무변경 — 백업 JSON에 필드만 추가되는 하위 호환 변경):

```ts
export interface SessionEntry {
  exerciseId: string;
  sets: SetRecord[];
  pairedWithNext?: boolean; // true면 다음 entry와 같은 화면에 묶어 표시 (슈퍼세트)
}
```

**그룹 정의**: 연속된 entry들 중 `pairedWithNext`가 이어지는 최대 구간. 마지막 entry의 flag는 무시(dangling 자가 치유). 3개 이상 체인(트라이세트)도 자연히 지원.

```ts
groupsOf(entries): number[][]  // 예: [A(p),B],[C] → [[0,1],[2]]
```

## 구성 요소

### 1. 세션 화면 — `SessionScreen.tsx` 재구성

- **네비게이션**: `idx`는 entry 인덱스 유지하되 화면 단위는 그룹. 이전/다음은 인접 그룹의 첫 entry로 이동, 상단 카운트·진행바는 `그룹 위치/그룹 수`
- **렌더**: 현재 그룹의 모든 entry를 카드로 세로 나열. 각 카드 = 운동 이름·태그(+`운동 빼기` 소형 버튼)·`🔥 지난번`/`📈 볼륨` pill·세트 목록·`＋ 세트 추가`/`− 세트 삭제`. 히어로 이미지는 **단독 그룹일 때만** (묶음은 컴팩트)
- **세트 조작 일반화**: `patchSet`/`toggleSet`/`addSet`/`removeSet`이 `entryIdx`를 명시적으로 받음 (묶음에서 각 운동 독립 조작). 휴식 타이머는 기존처럼 아무 세트 완료 시 시작
- **지난 기록 로드**: 그룹 내 운동별 `{last, pr}` 맵을 한 effect에서 로드 — deps는 `그룹 운동 id 문자열 키`와 `session.startedAt`만 (매초 재조회 금지 불변식 유지, 기존 spy 회귀 테스트 통과해야 함). 기준은 기존과 동일 `startedAt + 1`
- **묶기**: 하단에 `🔗 다음 운동과 묶기` 버튼 (현재 그룹 뒤에 entry가 있을 때) — 그룹 마지막 entry의 `pairedWithNext = true` 후 저장. `묶기 해제` 버튼 (그룹 ≥ 2) — 그룹 전체 entry의 flag 제거
- **운동 빼기**: `removeEntry(entryIdx)` — 완료 세트 존재 시 `confirm('완료한 세트가 있어요. 이 운동을 뺄까요?')`. 묶임 정리 규칙: 빼는 entry가 **그룹의 마지막**이면 직전 entry의 flag 해제(엉뚱한 다음 운동과 묶이는 것 방지), **그룹 중간**이면 직전 flag 유지(그룹이 축소되어 나머지끼리 유지). 제거 후 `idx`는 유효 그룹 시작으로 보정, 전부 빼면 기존 빈 상태 문구

### 2. picker — `ExercisePicker.tsx` + `sessions.ts`

```ts
getLastDoneMap(): Promise<Map<string, number>>  // exerciseId → 마지막 완료 세션 startedAt (완료 세션만, listFinishedSessions 최신순이라 첫 등장이 최신)
```

- picker에서 `useLiveQuery`로 로드. 필터(부위·검색) 적용 후 두 구간으로 분할:
  - **최근 한 운동**: 맵에 있는 운동, `lastDone` 내림차순, 각 행 서브라인에 `부위 · 기구 · M/D` (마지막 수행일)
  - **전체 운동**: 나머지, 기존 가나다순
- 최근 구간이 비면 헤더 자체를 생략. 구간 헤더는 기존 `card-h` 스타일
- RoutineEditor의 picker도 자동 적용 (prop 변화 없음)

### 3. 데이터 호환

- `finishSession`(`{...e}` 스프레드)·EditSessionScreen(깊은 복사)·백업 내보내기/가져오기 모두 `pairedWithNext` 보존 — 백업 왕복 테스트로 고정
- 요약·기록·과부하 계산은 entry 순회라 영향 없음

## 에러/엣지 케이스

- 마지막 entry에 dangling flag (짝이 빠진 경우): groupsOf가 무시 — 화면 정상
- 묶은 상태에서 운동 추가: 새 entry는 항상 단독 그룹, 이동은 그 그룹으로
- 빈 세션(entry 0개): 기존 빈 상태 유지, 묶기 버튼 미표시
- 최근 한 운동에서 진행 중(미완료) 세션은 집계 제외 (완료 기록만)
- 백데이트 세션에서도 묶기·빼기 동일 동작

## 테스트

- `groupsOf` 단위: 기본 분할, 체인 3개, dangling flag 무시
- SessionScreen: 묶기 → 두 운동 동시 표시·각각 세트 체크 저장, 새로고침(재마운트) 복원, 그룹 단위 이동(카운트 포함), 해제, 운동 빼기(즉시/confirm 분기, 묶임 정리, idx 보정), 기존 15개 테스트 무변경 통과 (매초 재조회 spy 테스트 포함)
- ExercisePicker: 최근 구간 정렬·날짜 표시, 검색·칩 필터 양구간 적용, 기록 없으면 구간 생략
- `getLastDoneMap` 단위: 최신 우선, 완료 세션만
- 백업 왕복에 `pairedWithNext` 보존
