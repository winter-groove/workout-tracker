# D 리디자인 마스터 설계 — 코치·다크 (플랜핏풍 재해석)

날짜: 2026-09-22

## 목적

앱 전체를 프로토타입 D(https://claude.ai/artifact/HUHSgaaXZzjk1mmCY1Wqcc 4번째 줄) 방향으로 재구성한다: 다크+라임 테마, "오늘 뭐 할지"를 먼저 제안하는 코치 홈, 한 세트 집중형 운동 화면, 통계가 앞에 오는 기록 탭.

## 사용자 확정 사항

- 기준: 프로토타입 **D안** (코치·다크). 목업의 구성 패턴을 따르되 재해석 — 타사 자산 복제 없음
- 운동 중 화면: **한 세트 집중 뷰로 전환** (기능은 전부 유지)
- 홈의 월 달력(백데이트 포함): **기록 탭으로 이동**
- 하단 탭: **3탭 — 홈 / 기록 / 마이** (코치 요소는 홈에 통합, 관리 → 마이)

## 불변 원칙 (모든 Phase 공통 게이트)

1. **데이터 모델·Dexie 스키마·백업 포맷 무변경.** 통계·코치 제안은 전부 기존 세션 기록에서 파생 계산
2. **기능 제거 0**: 슈퍼세트, 드랍세트(+휴식 억제), 운동별 단위(kg/lb·병기), 백데이트, 완료 세션 수정, 이어서 하기, 즐겨찾기, 총 볼륨·운동 시간, PR/증감, 백업 — 전부 그대로 동작
3. **코치 = 서버 없는 순수 함수 규칙 엔진** (`src/db/coach.ts`). 네트워크·신규 npm 의존성 금지
4. 매 Phase 종료 시점에 앱 완전 동작 + 전체 테스트 통과 + 배포. 기존 테스트의 동작 계약은 유지하고, 화면 문구·구조 변경으로 갱신이 필요한 테스트는 스펙/계획에 명시된 것만 갱신
5. UI 문구 한국어, 명품보쌈 브랜딩 유지

## Phase 1 — 다크 테마 기반 + 3탭 (구조 무변경)

- `styles.css` 토큰 재매핑 + 컴포넌트 보정(카드 그림자→테두리, startcard 그라데이션→surface+라임, .btn-primary→라임/on-accent, .set-row.done→라임 계열, .tag·.last-pill 다크 배경 등)
- 탭바: 홈 / 기록 / 마이 3탭, 이모지 아이콘 → 인라인 SVG 스트로크 아이콘, 활성=라임
- ManageScreen 화면 제목 '관리'→'마이' (경로·컴포넌트명 유지, 표시만)
- `vite.config.ts` manifest `theme_color`/`background_color` 다크, `index.html` meta theme-color, `scripts/generate-icons.mjs` 아이콘 배경 다크 재생성(명/보/품/쌈 유지)
- 게이트: 전체 테스트 무변경 통과(문구 불변), 빌드, 육안 대비 점검(본문 4.5:1)

## Phase 2 — 코치 홈 + 달력 이동

- 홈 = ① 날짜+인사("오늘은 {부위} 날이에요" — 추천 루틴 기반, 없으면 "오늘 뭐 할까요?") ② 코치 추천 카드: 오늘의 루틴(기존 todayRoutine 우선, 미선택 시 pickNextRoutine 결과를 자동 제안) + 운동 목록 프리뷰(지난 기록 세트×무게) + 예상 시간·볼륨(지난 세션 파생) + [운동 시작하기]/[루틴 바꾸기] ③ 주간 목표 링(주 N회, 이번 주 완료 수) ④ 연속 주 스트릭 ⑤ 코치 팁 카드 1개(규칙 우선순위: 진행 제안 > 부위 공백 > PR 축하 > 격려)
- `src/db/coach.ts`: `suggestToday()`, `weeklyGoalProgress()`, `weekStreak()`, `coachTip()` — 순수/파생 계산, 단위·드랍 등 기존 헬퍼 재사용
- 주간 목표 설정: 마이 탭 설정에 '주간 목표 (회)' (localStorage `wt-weekly-goal`, 기본 3)
- 진행 중 세션 카드·버리기 유지. 월 달력+백데이트+날짜별 세션 펼침은 **기록 탭 상단으로 그대로 이동** (SessionDetails 공용 유지)
- 게이트: 홈·기록 탭 테스트 갱신은 이동·문구 변경분만, 백데이트·펼침 동작 테스트는 기록 탭 렌더 기준으로 이전

## Phase 3 — 운동 중 집중 뷰

- 상단: 닫기 / "n / m · {세션명}" + 경과·볼륨 / 완료 버튼 + 운동 진행바(그룹 단위)
- 중앙(현재 세트): 운동명·세트 라벨(드랍 = "↓ 드랍") / 큰 숫자 무게×횟수(탭하면 직접 입력, 스텝 버튼 ±`stepFor(u)`) / 세트 도트(완료●·현재◎·대기○·드랍 표기) / 코치 팁 한 줄(지난 기록 대비)
- 하단 고정: [세트 완료] 큰 라임 버튼(완료 시 다음 세트로 포커스 자동 이동, 드랍 앞 휴식 억제 유지) + 휴식 타이머 바
- 세트 기록표(스크롤 영역): 전체 세트 리스트(라벨·무게·횟수·완료 표시, 드랍 들여쓰기), 행 탭 → 그 세트 포커스, 기존 [＋ 세트][↓ 드랍][− 삭제][운동 빼기][단위 ⇄][묶기/해제] 버튼 유지
- 슈퍼세트 그룹: 집중 뷰 상단에 운동 전환 칩(그룹 내 운동들) — 번갈아 기록 흐름 유지
- 게이트: 기존 SessionScreen 테스트의 **동작 계약**(저장·휴식 억제·드랍·단위·프리필) 전부 통과 — aria-label 체계(`세트 {라벨} 무게/횟수/완료`) 유지, 화면 구조 변경으로 깨지는 테스트는 동작 동일성을 보존하는 방향으로만 갱신하고 갱신 사유를 계획에 명시

## Phase 4 — 기록 탭 통계 + 마무리

- 기록 탭(위→아래): 주간 목표 링(소형)+스트릭 / 볼륨 추세 라인차트(최근 8주, `sessionVolume` 주별 합, 인라인 SVG) / 하이라이트(최근 PR·볼륨 증감·부위 공백 — coach.ts 재사용) / 월 달력(Phase 2에서 이동해 옴) / 세션 목록(기존 행·펼침·수정·삭제) / 운동별 보기(기존)
- 마이 탭 정리: 프로필 헤더(이름 없음 — "명품보쌈 멤버"), 루틴·운동 목록·설정(휴식/단위/주간 목표)·백업 기존 기능 재배치
- 게이트: 전체 회귀 + 최종 브랜치 리뷰

## 에러/엣지 케이스

- 기록 0개 신규 사용자: 코치 카드가 "첫 운동을 시작해보세요" + 빈 세션 시작으로 대체, 링 0/3, 추세 차트 빈 상태 문구
- 루틴 0개: 추천 없이 빈 세션 유도(기존 동작 유지)
- 주간 목표 변경 시 링 즉시 반영(localStorage 패턴 기존과 동일)
- 백데이트 세션: 스트릭·주간 링 계산은 startedAt 기준(기존 달력과 동일 기준)
- lb 단위 운동: 집중 뷰 큰 숫자·스텝·코치 제안 전부 표시 단위 기준(저장은 kg 불변)
